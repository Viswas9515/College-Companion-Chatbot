 # College Companion Chatbot

## Description
AI-powered chatbot designed to assist students with academic and administrative queries using NLP techniques.

## Features
- Intent classification & entity recognition
- Academic query handling
- Course & event information
- Automated responses
- Scalable architecture

## Tech Stack
- Python
- Flask
- Rasa
- MySQL
- HTML, CSS, JavaScript

## How to Run
pip install -r requirements.txt  
python app.py
